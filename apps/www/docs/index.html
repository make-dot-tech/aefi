How to read confidence

Every important response is an envelope: a summary, a confidence label, reasons, evidence refs, and coverage. If aefi cannot see mandate or task authority, it returns authorization_evidence_missing instead of pretending. Details in Evidence model.

The live graph is Arc testnet. IDs and matcher cursors include chain_id, so mainnet is a new ingest plane, not a rewrite. See Arc.
